# Portfolio Website

Portfolio website pribadi dengan desain glassmorphism menggunakan React, Tailwind CSS, dan Framer Motion.

## Teknologi

- React
- Tailwind CSS
- Framer Motion
- Vite
- React Router DOM
- Heroicons
- React Icons

## Fitur

- Desain glassmorphism
- Animasi smooth
- Responsive mobile
- Navigasi antar halaman
- Timeline pengalaman
- Skills dengan progress bar
- Contact form

## Cara Menjalankan

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev

# Build untuk production
npm run build
